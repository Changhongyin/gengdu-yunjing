## 资源加载与打包

图片加载统一经过 `utils/asset-source.js`：云文件先下载为设备可读路径，再更新页面；并发请求合并，缓存失效后重新下载，页面退出和关卡切换后不会回写过期结果。云服务暂不可用时不会中断应用启动。

当前按用户要求采用本地原画质资源，不再以发布包大小或 200 K 质量建议为目标。`utils/cloud-assets.config.js` 保持 `enabled: false`，无需云存储权限或付费服务。

原版本 120 张图片的质量配置继续保留；本次新增实景见上方更新说明。PNG 直接使用原始文件，保留原始尺寸、色彩与透明通道；7 张 JPG 使用 `assets/highres/` 中的无损复制文件，其中 5 张来自压缩前备份 `output/upload-originals/`。它们没有再次编码或降采样。旧轻量文件留在磁盘，但已从当前路径映射、静态模板及打包清单中排除。

`scripts/optimize-runtime-assets.cjs` 默认生成原画质资源、`utils/asset-runtime.js` 和 `output/runtime-media.json`；仅显式传入 `--light` 时才生成轻量版。脚本依赖 Sharp，可通过 `SHARP_MODULE` 指定模块位置；小程序运行时没有新增依赖。修改资源后执行：

```sh
node scripts/optimize-runtime-assets.cjs
node scripts/prepare-upload.cjs
node scripts/check-upload.cjs
node scripts/check-media-quality.cjs
```

`check-upload.cjs` 默认校验所有运行时资源都随包，并报告体积；`--strict` 可显式启用发布体积门槛。当前本地源码包约 3.85 MB，优先保证清晰度和离线显示，未处理正式发布的包大小限制。`check-media-quality.cjs` 逐字节比较运行时资源与最佳本地原件，防止重新误用低清缩略图。

若未来恢复云资源，必须先解决权限及文件路径问题，再逐文件验证客户端下载，不能只打开映射开关。页面退出保护、缓存失效处理与失败重试机制均保留。`project.config.json` 显式保留 JS 数据与静态模板引用的原画质图片；AppID 保持现有配置。

原始大图备份位于 `output/upload-originals/`。独立网页仍在 `web/panorama/dist/`，两者均不打入小程序包。

这是可在微信开发者工具中直接导入的原生小程序工程。原始设计稿 `index.html` 和图片保留；小程序从 `app.json` 注册的页面启动。

## 720云全景与高清

全景页点击「720云实景漫游」，可打开指定网页或复制链接：

https://www.720yun.com/vr/750jezhm5k0

全景网址在 `app.js` 的 `globalData.panoramaUrl` 配置。小程序使用原生 `web-view` 承载720云，网页将全屏显示。真机中，账号须支持该组件并完成业务域名配置；第三方域名通常还需要域名所有者协作校验。域名配置和网页内部资源由对应平台控制。若不能嵌入，可复制链接到浏览器打开。项目保持域名校验开启。

**此次未取得或替换720云的源照片，不能声明原站照片已经变为1080p。**

千年古樟内置了两份本地 2:1 球形实景：2560×1280 原始照片与 1774×887 增强照片，均使用压缩前备份随包。默认显示像素更高的原片，可切换增强图。进入这一关默认自动展开 360° 查看器，无需下载云文件。已在开发者工具模拟器中逐项验证：实景呈现、手势拖动、按钮缩放、自动环游/暂停、重置视角、原片/增强图切换，以及切换景点后返回重新加载。双指缩放的手势处理另有回归检查，真机手势及设备兼容性仍待实机验证。

其他三个景点已替换为对应调研实景照片。照片不具备球形投影，不会作为虚假的 360° 全景展示。

已加入独立的原生 WebGL 高清查看器：「导入高清全景」从相册选择原始 JPG/PNG，要求接近 2:1 的等距柱状球形全景。查看器以屏幕短边 1080 像素作为渲染目标，按视窗比例确定长边，保留原图纹理，不将截图冒充高清原图。支持拖动、双指缩放及重置视角，并显示真实的原图和渲染分辨率。渲染不等同于照片超分辨率增强。

360°图像的像素覆盖整个球面，建议提供至少 4096×2048 的原图；全景1080像素高也不等于每个视角都具备1080p细节。硬件最大纹理尺寸随设备不同，超过限制会明确提示。导入的照片仅在本次页面使用，不上传。现有插画 `image_358.png` 为343×365，仅用作设计示意。

实景嵌入受账号和第三方页面条件影响；内置全景已通过模拟器验证，真机上的 WebGL、双指手势和高分辨率导入仍需实机确认。
